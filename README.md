# Lots collector (goszakup, 2025)

Скрипт `collect_lots_2025.py` собирает лоты с `goszakup.gov.kz` по списку кодов ТРУ из Google Sheets.

## Что делает

1. Читает входную таблицу (столбцы `Код ТРУ`, `Название`).
2. По каждому коду ТРУ выполняет поиск лотов на `goszakup`:
   - `year=2025`
   - фильтр статуса (по умолчанию `360`)
   - фильтр суммы от (по умолчанию `15000000`)
3. Обходит пагинацию и сохраняет результат в CSV со столбцами:
   - `№ лота`
   - `Код ТРУ`
   - `Наименование товара`
   - `Наименование объявления`
   - `Наименование и описание лота`
   - `Кол-во`
   - `Сумма, тг.`
   - `Способ закупки`
   - `Статус`

## Запуск

```bash
pip3 install -r requirements.txt
python3 collect_lots_2025.py
```

По умолчанию результат сохраняется в:

`output/lots_2025_by_tru.csv`

## Полезные параметры

```bash
python3 collect_lots_2025.py \
  --workers 6 \
  --max-codes 100 \
  --max-pages-per-code 3 \
  --output output/sample.csv
```

- `--max-codes 0` — обработать все коды (по умолчанию).
- `--max-pages-per-code 0` — без лимита страниц (по умолчанию).
- `--status ""` — отключить фильтр статуса.
- `--amount-from 0` — отключить фильтр суммы.
