# Сбор лотов goszakup по кодам ТРУ

Скрипт `sync_goszakup_lots.py` собирает лоты с портала `goszakup.gov.kz` по кодам ТРУ из входной Google-таблицы и формирует CSV в формате:

- № лота
- Код ТРУ
- Наименование товара
- Наименование объявления
- Наименование и описание лота
- Кол-во
- Сумма, тг.
- Способ закупки
- Статус

## Установка

```bash
pip3 install -r requirements.txt
```

## Запуск (фильтры по умолчанию как в примере)

```bash
python3 -u sync_goszakup_lots.py --output-csv lots_2025_by_tru.csv --workers 12
```

Параметры по умолчанию:

- `year=2025`
- `status=360` (Закупка состоялась)
- `amount_from=15000000`

## Полезные параметры

- `--only-codes` — запуск только по указанным кодам (через запятую)
- `--limit-codes` — ограничить количество кодов для теста
- `--workers` — число параллельных воркеров
- `--amount-from -1` — отключить фильтр минимальной суммы
- `--status ""` — отключить фильтр статуса

## Попытка записи в Google Sheet

Можно включить флаг `--write-google-sheet`, если в окружении доступны сервисные учетные данные:

- `GOOGLE_SERVICE_ACCOUNT_JSON` (JSON-строка)
или
- `GOOGLE_SERVICE_ACCOUNT_FILE` (путь к json-файлу)

Без учетных данных скрипт просто сохранит локальный CSV.
